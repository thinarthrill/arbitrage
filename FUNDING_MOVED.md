# Funding strategy moved

The independently executable funding-arbitrage bot, read-only scanner, paper simulation and historical funding availability matrix have moved to the private repository [thinarthrill/funding](https://github.com/thinarthrill/funding).

This repository keeps its existing price-arbitrage engine unchanged. It still contains legacy funding estimates embedded in `arbitrage_price_cross.py` for historical compatibility; **do not treat that old integrated code as the new funding strategy**. For demo funding trading, use the separate repo.
